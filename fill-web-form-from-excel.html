How to fill a web form from an Excel or CSV file, without code

Many portals and back-office systems have no import button, so someone copies each spreadsheet row into a form by hand. Here are your options, starting with the one to check first.

1. Look for an import or API first

Search the site's help pages for "import", "bulk upload" or "API", or ask its support team. If one exists, use it: it's usually the quickest and most reliable route.

2. Write a script

Browser automation tools can drive a form from a file. They suit technical teams with a large, fixed job, but someone has to write the script and fix it when the page changes.

3. Use a desktop automation tool

Robotic process automation tools can record clicks and repeat them. They're powerful but take time to set up, and may need your IT team's approval.

4. Use a browser extension

This suits everyday work where a person still wants to check each record. Using RowPilot as the example:

  1. Save your sheet as CSV or .xlsx, with the column names on the first row.
  2. Open the form in Chrome and click the RowPilot icon.
  3. Load the file and click Read the form on this page.
  4. Check which column goes in each field.
  5. Fix anything listed under Check your rows.
  6. Click Fill this row, review the page and submit it yourself.
  7. Click Mark done, go to next and repeat.

Avoiding common mistakes

  • Dates: decide whether 03/04/2026 means March or April before you start. RowPilot asks you.
  • Dropdowns: your cell has to match one of the form's choices. Check these first.
  • Leading zeros: a spreadsheet may turn 00123 into 123. Format ID columns as text before exporting.
  • Site rules: some sites restrict automated tools, so check their terms first.
