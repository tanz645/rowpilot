How to attach a different file to each web form entry

Some forms need a different contract, invoice or photo for every record. Finding the right file by hand for each entry is slow, and picking the wrong one is an easy mistake to make. You can avoid that by listing each file's name in your spreadsheet.

First, check for a bulk upload

Some systems accept a zip file or have a bulk document upload that matches files by name. If yours does, use it. The method below is for forms that take one file per entry.

Step 1: Add a file name column

Add a column to your sheet with the exact file name for each row, including the ending, such as contract-ayesha.pdf. Keep the column simple:

NameEmailContract
Ayesha Rahmanayesha@example.comcontract-ayesha.pdf
Lukas Weberlukas@example.orgcontract-lukas.pdf

Step 2: Put the files in one folder

Give every file its own name, because two files with the same name can't be told apart, even in different subfolders. Each file has to be 25 MB or smaller to attach with RowPilot, and the website may set a lower limit.

Step 3: Fill the form

  1. Open the form in Chrome and click the RowPilot icon.
  2. Load your spreadsheet and click Read the form on this page.
  3. Match your file name column to the form's upload field.
  4. Click Choose the folder with the files to attach and pick your folder. Chrome will ask you to confirm.
  5. Check your rows. Any name with no matching file is listed before you fill anything.
  6. Click Fill this row, check the file name shown on the page, and submit it yourself.

Attaching files is part of RowPilot Pro, which you can try for 7 days.

Avoiding mismatched files

  • Use names you can check: a name like contract-ayesha.pdf is easy to compare with the row on screen. scan0041.pdf isn't.
  • Upper or lower case doesn't matter: Contract-Ayesha.PDF matches contract-ayesha.pdf, but a missing or different ending won't match.
  • Full paths are fine: if your sheet lists a full path, only the file name at the end is used.
  • Several uploads per entry: use one column for each upload field. One cell holds one file.
  • Sensitive files: files are read in your browser and go only into the page you ask it to fill. After that, the website's own policies apply.
