How to fill a web form from Google Sheets

If your data is in Google Sheets and the website has no import option, you don't have to re-type each row. The right method depends on whether you can write code, and whether someone needs to check each entry.

First, check for a direct route

Look for an import, bulk upload or API option in the website's help pages. If it has one, use it. Automation services can also connect Google Sheets to many popular apps, but they only work with apps they support, which usually rules out private portals.

Option 1: Write a script

Google Apps Script can send sheet rows to a service that offers an API. For a website with only a form, you'd need a browser automation script instead. Both suit a technical team with a large, repeating job, but someone has to maintain the code.

Option 2: Paste rows into a browser extension

This is the quickest way to start, and it suits work where a person reviews each entry. There's no file to download. Using RowPilot as the example:

  1. In Google Sheets, select your rows, including the column names at the top, and copy them.
  2. Open the form in Chrome and click the RowPilot icon.
  3. Click Or paste rows copied from a spreadsheet, paste, and click Use pasted rows.
  4. Click Read the form on this page and check which column goes in each field.
  5. Fix anything listed under Check your rows.
  6. Click Fill this row, review the page and submit it yourself.
  7. Click Mark done, go to next and repeat.

Option 3: Download a file first

In Google Sheets, choose File → Download → Comma-separated values (.csv). This saves only the sheet you have open. Then load that file instead of pasting. A file is handy when you want to keep an exact copy of what you entered. RowPilot's free plan reads CSV; Excel files (Microsoft Excel (.xlsx) on the same menu) need Pro.

Common mistakes

  • No column names: the first row you copy is treated as the column names, so include them.
  • What you see is what gets copied: a date shown as 3/4/2026 is copied that way. Decide whether it means March or April, and choose the matching date order in the panel.
  • Lost zeros: Google Sheets may turn 00123 into 123 when you type it. Set ID columns to Format → Number → Plain text before you enter them.
  • Changing data midway: fix your sheet before you start. RowPilot tracks progress for that exact set of rows, so changed data starts a new count.
  • Site rules: some sites restrict automated tools, so check their terms first.

Try it on your own form. RowPilot is a Chrome extension. The free plan covers up to 25 rows per file from a CSV or pasted rows, and every install starts with a 7-day trial of Pro.
